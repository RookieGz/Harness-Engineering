# Purpose
Create a page task document from product, design, and API inputs.

# Inputs
- product doc
- UI design source
- API doc

# Outputs
- tasks/page-xx.md

# Rules
- planning only
- no source code changes
- name exact route, frames, endpoints, viewports, and required states
- record blocking decisions instead of guessing

# Required sections
- Objective
- Inputs
- Route
- Required Viewports
- Required States
- In Scope
- Out of Scope
- Files or Directories to Inspect
- Acceptance Criteria
- Validation Commands
- Evidence
