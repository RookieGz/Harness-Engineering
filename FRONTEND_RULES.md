# Frontend Rules

## Flow
1. Read product doc.
2. Read design source.
3. Read API spec.
4. Build static UI with mock data.
5. Validate visual output.
6. Add interaction states.
7. Integrate API.
8. Validate API behavior.
9. Collect evidence.

## Rules
- Keep changes scoped.
- Do not modify unrelated files.
- Record blocking decisions instead of guessing.

## Done when
- required viewports pass
- required states pass
- screenshots and test output exist
